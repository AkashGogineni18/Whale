Pillar 01

Whale AI

Every user gets a personal AI that understands their own conversations — not a per-group bot, but an assistant that follows you across chats. This is the core of what makes Whale next-gen: chat that gets smarter the more you use it, instead of just piling up.

Personal assistant

  • Summarize unread messages across a chat or Band
  • Surface what a specific person said on a specific topic
  • Turn a conversation into action items
  • Detect and pin decisions automatically
  • Draft replies, reminders, and translations on request

Semantic search

Search by meaning, not exact wording — "that message about Charan explaining the weekend trip" finds the message even if those aren't the words used. Search spans messages, people, files, tasks, decisions, links, scheduled messages, and voice notes.

AI rewrite — user-approved, never silent

Rewrite suggestions (translate, fix grammar, make professional, make friendlier, make shorter) are shown before sending, never applied automatically. You approve every change.

Chat memory

Ask a Band directly: "What did we decide about the Boise trip?" or "What files did Shareef send last week?" — the AI holds context per-room, scoped to that Band.

Smart file vault

Every Band gets an organized file system instead of files buried in scrollback: all files, large files, images, videos, documents, expired files, shared-by-me, downloaded-by-others, and AI-generated summaries on request.

Scheduled messaging

  • Schedule to one person, one Band, or several Bands at once
  • Recurring sends with timezone awareness
  • Optional approval step before a scheduled message goes out
  • Edit or cancel anytime before send

Smart notifications

Messages are triaged — urgent, needs reply, FYI, task, decision, file shared, social — so low-priority chatter can be summarized later instead of interrupting now.

Pillar 02

Whale Tunnel

Uncompressed, always

A secure large-file sharing channel that sends originals — never a compressed preview. Files are split into encrypted chunks, held temporarily on Whale's servers, and deleted after successful delivery or expiry.

Capabilities

  • Original quality — no re-encoding of photos, video, or audio, ever.
  • Resumable transfer — chunked upload and download can pause and resume, with live progress tracking.
  • Expiring access — set a tunnel to close after a fixed window (e.g. 48 hours).
  • One-time download — file is removed the moment it's retrieved.
  • Password-protected tunnels — an extra credential layer beyond chat access.
  • Revoke anytime — sender can kill an active tunnel before it's collected.
  • Download status — see exactly when, and by whom, a file was picked up.
  • Auto-delete — chunks clear from Whale's servers after delivery or expiry, whichever comes first.

Architecture

Trust & encryption model

Whale runs two distinct modes rather than one blanket claim. AI needs to read content to be useful; true privacy means no one — including Whale — can read content at all. Rather than blur that line, each chat is explicitly one or the other.

Cloud Mode — default

Powers Whale AI, search, sync, and Bands
  • Message encrypted in transit (device → server)
  • Server decrypts to run AI processing
  • Content re-encrypted at rest, key-managed via KMS/HSM
  • Delivered to recipient device

Privacy Mode — opt-in per chat

True end-to-end — the server never holds the key
  • Keys generated and held only on sender/receiver devices
  • No screenshots, no forwarding
  • Messages auto-delete, files expire
  • AI cannot process this chat — it has no key to do so
